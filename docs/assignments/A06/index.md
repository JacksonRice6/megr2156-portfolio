Once I got it all designed I was ready to put it in a drawing. It was very simple. I added the part and put it in third-angle projection. After that I dimensioned it. It was a little hard to make it look neat and professional, but I think the result was good. I also had to make sure I had all the dimensions, but not to over dimension. I added a centerline to show symmetry that way I can cut down on how many dimensions I would use. I still had to get every dimension needed though. To do this I imagined drawing it from scratch, did I have what I needed? Once I got all the dimensions I made the title block. I put it the tolerances then I had to go back and add those tolerances to the dimensions. In the end it turned out well.

## Decide

For this I decided where to put dimensions and how to orient them. I just decided to make each dimension between the views(as best I could) and to make them all line up. I also decided to add a centerline to show the symmetry instead of assuming it.

## Communicate

I used the stiffness analysis for the dimensions. This was because a lot, if not all, the dimensions were larger values than the stress analysis. This means in order to allow for the max stress AND max deflection I should use these dimensions. I used the equations for almost all of the dimensions. One specific one was the diameter of part A. I put the equation in the parametric equations so then if I even changed something like the moment of inertia then it would affect the dimension. I found out in my hand calculation I wrote 2.5 instead of 1.5 so I corrected it in SolidWorks and it affected the width of a part which affected the other parts. Luckily, this was done automatically because I had inputted all the equations earlier.

Most dimensions had the same tolerances, however the parts where the T-beam slides in I kept tighter. This is because any sliding fit needs to be much more precise than other dimensions. Now, most of the tolerances had a .01 precision and this might be a little tight. Because for parts that don't matter as much you're wasting money to keep the tolerance so tight. For these I should have made them looser.
